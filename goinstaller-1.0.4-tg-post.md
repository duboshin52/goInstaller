**goInstaller 1.0.4: сам находит, почему GitHub «не отвечает», и чинит по вашему согласию**

Если при установке вы видели `curl: (28) SSL connection timeout` и совет «проверьте ключ» — ключ был ни при чём. Разобрались на сервере подписчика, теперь goInstaller ловит это сам.

**Что было**

Некоторые хостеры настраивают сетевую карту сервера на пакеты в 1500 байт, а их сеть пропускает меньше. На том сервере — 1452. Мелкие пакеты проходят, а крупный ответ GitHub застревает на узком месте, и соединение рвётся через раз. Отсюда плавающие сбои: то не опрашиваются версии, то не скачивается установщик.

**Что теперь**

— При открытии меню goInstaller проверяет, какой размер пакета реально проходит до GitHub, и сам подбирает число.

— Если сеть у́же, чем настроена карта, он скажет это прямо и спросит: «Изменить размер пакета сетевой карты на 1452? 1) Да / 2) Нет».

— По «Да» ставит размер, проверяет, что пакеты теперь доходят, и записывает настройку, чтобы она пережила перезагрузку. Не помогло — вернёт как было и ничего не запишет.

— Без вашего ответа ничего не меняет. Отказались — больше не спросит, пока сеть та же.

— Сбой связи с GitHub теперь так и называется, без отсылки к ключу, а скачивание повторяется до трёх раз.

Проверить вручную в любой момент:

```bash
goinstall --net
```

**Как обновиться**

```bash
goinstall --self-update
```
