# Дополнение к пакету «Аркада»: «Защита от сканеров», goInstaller 1.2.3

```
goInstaller Shield Stats.dc.html    прототип: главное меню + экраны защиты (рядом support.js, shield-screens.js, menu-screens.js)
shield-screens.js                   построитель экранов sh-a…sh-h — эталон строк
menu-screens.js                     главное меню g1 / g2 (функции прототипа v2 + пункты c, s, x и защита)
spec/screens/arcade_shield_{ru,en}.json   sh-a…sh-h, 80 и 46
spec/screens/arcade_menu_{ru,en}.json     g2 · 80, g1 · 80, g1 · 46 × размещение A/B × курсор 1 / s
spec/tokens-shield.json             новые токены in, out
spec/ascii-fallback-shield.json     ▁▂▃▅▇ и ┊
```

## Два счётчика

- **Вход · сканеры остановлены:** N попыток · M адресов. Выкл — «Вход · выкл · только считает».
- **Выход · утечка IP предотвращена:** K соединений к сетям ВК. Выкл — «Выход · выкл · защита от утечки IP не работает», токен warn.
- Разбивка выхода «клиенты VPN / сам сервер» — в sh-f (и в данных sh-e).

## Пирамида (основной график)

- По центру колонка подписей постоянной ширины, по бокам две нулевые линии `│` в постоянных колонках.
- Вход растёт от левой линии влево, выход — от правой вправо. Полосы сплошные, конец — половинка `▐` (слева) или `▌` (справа); значение меньше половины клетки — `▕` / `▏`.
- У каждой стороны своя шкала: `niceMax` — шаг 1, 2 или 5 × 10ⁿ, не больше 4 шагов. Сетка `┊` (токен shadow) — на каждом шаге, видна там, где нет полосы. Под графиком — зеркальные подписи шкал, в оси — «шкала», нулевые линии заканчиваются `┴`.
- Строка выделяется стрелками (фон sel только в пределах графика); точные числа строки — в правой колонке (80) или строкой под графиком (46). В карточке меню — ←→, числа в предпоследней строке карточки.
- Представления 1–4: 24 часа (строка = 2 часа, 12 строк), 7 дней (строка = день), месяц (строка = 2 дня на 80, 3 дня на 46), всё время (строка = месяц).
- Вход и выход различаются стороной, стрелкой в подписи и тоном (in — насыщенный, out — светлый того же цвета).

Столбики (прежний вариант) — переключатель «График» в прототипе, в JSON — `chart: "bars"`.

## Экраны

| id | что |
|---|---|
| sh-a | уведомление: обе строки «пока вас не было», строка «▲ Всплеск», топ (80: 2–3 сети, 46: одна или ни одной при всплеске) |
| sh-b | защита выкл, спокойная рекомендация |
| sh-c | «Защита: вкл · за сутки: вход 0 · выход 0» |
| sh-d | меню «Защита»: 1–9 и 0, карточка с пирамидой за 7 дней |
| sh-e | статистика: пирамида, справа (80) — строка, пик, всплеск, новые и повторные адреса, порты с пометкой, чей порт |
| sh-g | топ-30: №, AS, сеть, попыток, адресов, последний раз, порт; период 1–4, ↑↓, PgUp PgDn, Home End |
| sh-h | настройки: с какой даты, размер на диске, адресов в памяти, «Обнулить» → 1 Да / 2 Нет, Enter — Нет |
| sh-f | без tty: ключ раздела в первой колонке (`вход`, `выход`, `день`, `час`, `порт`, `топ24ч`, `топ7д`) |

Всплеск — час (или день) с попытками не меньше чем в 2 раза выше медианы периода.

## Главное меню

- **A · под списком:** g2 — последняя строка левого окна, g1 · 80 — колонка пояснения у пункта s, g1 · 46 — пустая строка перед замечаниями.
- **B · в строке сведений:** строка 23, на 46 — «вх / вых».
- Курсор на s: g2 — карточка справа, g1 — две строки счётчиков на месте описания продукта.
- Какие строки эталона меняются — поле `shield_rows` в arcade_menu_*.json и панель «Что меняется» в прототипе. g1 · 80 в эталоне не содержит c, s, x — они добавлены, пустая строка перед замечаниями убрана.

## Допущения

- Все числа условные; AS — только документационные номера 64496–64511 и 65536–65551.
- Пометки портов взяты с сервера-примера: 22 SSH, 443 VLESS, 80 сайт-маска, 2443 MTProxy, 853 DoT, 3389 свободен.
- `┊` нет в таблице символов прежнего брифа — добавлен по решению владельца, ASCII `:`.
