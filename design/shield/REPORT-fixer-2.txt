СЕРЬЁЗНЫЕ
1. grep -c || echo 0 → «0\n0» → «уже 1000 строк» после удаления последней строки.
   Закрыто 6b80050: n=$(grep -c . f); case-очистка до числа (add и del).
   Тест: «: > exclude; shield_list_add exclude …» → rc 0, строка в файле.
   Мутация «как было» (|| echo 0, без case) в add → FAIL=3. В del та же строка — 0 упавших: на пустом
   файле удалять и так нечего (ошибка там не проявлялась), правка del — для единообразия.
   (Первая попытка мутации оставила case — прошла зелёной, т.к. case сам чинит «0\n0»; переделана.)

2. Смену порта SSH видел только часовой тик; провал пересборки молчал.
   Закрыто 8856ca6 + 6b1268d: _shield_fp_sync в начале shield_check — значит check, тик, postcheck,
   меню и «Аркада» (shield_state --live), --watch. Не пересобралось — журнал, result=fail, rc 1, текст.
   .path-юнит: PathChanged sshd_config, sshd_config.d, ssh.socket, ssh.socket.d → такт сразу.
   Тесты: фикстура 22→2222 → shield_check → 2222 в shield.nft; то же через shield_state --live;
   nft-заглушка падает → rc 1, result=fail, «порты SSH сменились, а правила не пересобрались».
   Мутации: убрать сверку из check → FAIL=9; провал молча → FAIL=4; .path без sshd_config.d → FAIL=1.

3. Юнит звал текущий goinstall (его подменяют --self-update main, bash <(curl …main…)).
   Закрыто 6b1268d — как runner обновления Ubuntu: копия shield/runner.sh (0700),
   ExecStart=/bin/bash runner.sh --shield tick, ConditionPathExists=runner.sh.
   Копию кладёт только файл ЭТОЙ версии с shield_cli() ($0 или goinstall); копию новее не трогает.
   shield_sync (старт меню/--install, --watch, команды --shield) освежает копию и юниты.
   Тесты: goinstall — заглушка без --shield → ExecStart на runner, cmp runner = скрипт, 0700;
   такт через runner проходит; прежний юнит (ExecStart на goinstall) sync переписывает; копию 9.9.9
   не трогает; без перемен systemctl не зовёт.
   Мутации: ExecStart на goinstall → FAIL=2; без ConditionPathExists → FAIL=1;
   перезапись копии новее → FAIL=2; offer без shield_sync → FAIL=1; без предупреждения → FAIL=2.
   ВЫБОР для self_update на версию без защиты: правила ОСТАВИТЬ и предупредить
   (shield_self_update_note в self_update и self_install): «защита продолжает работать… снять:
   bash /opt/go-installer/shield/runner.sh --shield remove --yes». Почему не снимать: молчаливое
   снятие при обновлении неожиданно открывает сервер сканерам — человек его не просил; копия
   самодостаточна (свои списки, свой nft-код), так что работающая защита не ломается.
   Остаток: --uninstall версии без защиты снимает каталог (и runner), а юниты не знает — служба
   пропускается по Condition (не падает), таблица живёт до перезагрузки. В «Как откатить».

4. Охват чужого списка не ограничен; ВК не проверялся.
   Закрыто 6abc013: _shield_py считает охват после слияния в /24 (v4) и /48 (v6).
   Числа (списки 03.11.2026): общий v4 — 1151 строка, 1658 /24 (самая широкая /16);
   ВК v4 — 739 /24, целиком внутри общего; общий v6 — 1 437 701 /48; ВК v6 — 1 572 864 /48.
   SHIELD_MAX4 = 16384 /24 (= одна /10, 0,1 % IPv4) — ~9,9× нынешнего общего: запас на рост
   проекта на порядок, а подменённый список закроет не больше /10, а не весь IPv4.
   SHIELD_MAX6 = 16 777 216 /48 (= 256 /32) — ~11,7× общего v6, ~10,7× ВК v6.
   Рост охвата за одно обновление — не больше 3× прошлого принятого (поля u4 u6 uvk4 uvk6 в meta;
   у meta прежней версии полей нет — рост в первый раз не судим, потолок судим).
   ВК v4 ⊆ общего v4 (_shield_py within, rc 7): ВК режет исходящие, чужая сеть (GitHub) отрезала бы
   сервер. ВК v6 так не проверить: у проекта две /29 ВК v6 вне общего v6 — только потолок и рост.
   Тесты: «все /8 кроме служебных» (217 строк, меньше 3× строк) → отказ «больше потолка 16384»;
   +10 /16 → «охват вырос больше чем втрое: 3235 против 675»; ВК v4 + 140.82.112.0/20 → «вне общего»;
   ВК v6 /16 → «больше потолка»; во всех — прежний список цел.
   Мутации: потолок → FAIL=3; рост → FAIL=3; ВК внутри → FAIL=2; охват по строкам (без слияния) → FAIL=3.
   Остаток: подделка в пределах потолков (до /10) всё ещё может накрыть чужие адреса; ВК v4 вне
   общего у самого проекта будет отклонён — через 3 суток это ✗ с причиной, не тишина.
