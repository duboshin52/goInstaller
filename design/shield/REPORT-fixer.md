## Что сделано и где (go-installer.sh)

- **Пути и окружение.** `_shield_paths`: каталог /opt/go-installer/shield (0700), в тестах `GOINST_SHIELD_DIR`. `_shield_nft` — вызов nft (в тестах заглушка). `_shield_py` — python3 -I с umask 077. Команды `_shield_py`:
  - list — строгий разбор списка;
  - addr — проверка адреса, введённого человеком;
  - tvk — сети TVK-AS из blacklist_with_comments.txt;
  - render — сборка shield.nft.
- **Скачивание: `shield_fetch`.**
  - Хеш коммита main берётся из api.github.com (`application/vnd.github.sha`), файлы — по `raw/<sha>/`. Хеш не получен — качает по ветке.
  - Идёт через `gh_curl` с отдельным конфигом 0600 без Authorization. Разрешён только https, не больше 8 МБ.
- **Приём списка: `shield_accept`.** Мусор, сеть шире /8 (v4) или /16 (v6), меньше 300 строк, меньше половины прошлого или больше 3× → отказ всему списку. Тогда работает прошлый принятый, а событие пишется в журнал и статус. Частные и служебные сети и сети с адресом сервера выбрасываются по одной, с записью в журнал.
- **Применение: `shield_apply` и `_shield_nft_load`.**
  - Сборка идёт в shield.nft.new. Файл: `table {}`, `delete table`, полное определение.
  - Сначала `nft -c -f`, потом `nft -f`. Только после успеха файл переименовывается в shield.nft.
  - Цепочка incoming: prerouting, priority -150. Порядок: lo accept → established,related accept → порты SSH accept → @allow4/@allow6 accept → @scan4/@scan6 counter drop.
  - Цепочки vk_forward и vk_output: @vk4/@vk6 counter reject (tcp reset, icmpx admin-prohibited).
  - Наборы: flags interval, auto-merge.
- **Исключения.**
  - Всегда: адреса сервера (`shield_addrs`), частные и служебные диапазоны, TVK-AS (по умолчанию), свои исключения человека.
  - Свои добавки — отдельный список.
  - Исключение сильнее добавки.
- **Порты SSH: `shield_ssh_ports`.** Берёт порты из уже имеющихся в 1.1.0 osup_ssh_ports --daemon и osup_ssh_cfg_ports и пересчитывает при каждом применении.
- **Самопроверка: `shield_live_ok`, `shield_check`.** Таблица на месте, цепочки есть. Непусты должны быть те наборы, что непусты в загруженном shield.nft: пустой список ВК поломкой не считается. Счётчики отброшенных и отклонённых пакетов показываются на экране.
- **Таймер: `shield_tick`** (`goinstall --shield tick`, раз в час со сдвигом до 10 мин).
  - Правил нет или они неполные — применить заново, «восстановлено».
  - Сменились порты SSH или адреса сервера — пересобрать правила.
  - Список старше 24 ч — обновить.
- **Юниты: `shield_units_write`.** goinstall-shield.service (oneshot, при загрузке применяет сохранённое) и goinstall-shield.timer.
- **Установка nft: `shield_apt_nft`.** Ставит ровно пакет nftables, только по «Да», nftables.service не включает. Это третье разрешённое место apt; страж apt учитывает исключение.
- **Поддержка сервера: `shield_support`.** Контейнер OpenVZ/LXC или ошибка применения → «не поддерживается», сказано словами, правила не ставятся.
- **Установка и снятие:** `shield_install`, `shield_teardown`, `shield_remove`. Удаление goInstaller (goinst_uninstall) снимает защиту и говорит об этом в подтверждении.
- **Предложение: `shield_offer`.** Зовётся в main для меню и --install после lang_persist, до ключа и продуктов (стр. ~11035 и ~11064), только при tty.
  - Текст в 3–4 строки, «1) Да / 2) Нет», умолчание «Да» (как у MTU).
  - Отказ записывается в файл состояния.
  - Списки не скачались — сказать причину и предложить в следующий раз.
- **Проверка после установщиков: `shield_postcheck`.** Стоит рядом с installer_postcheck: install_flow (~3390), запуск из «Аркады» (~10417), --install (~11047).
- **Меню: `shield_menu_line`, `shield_menu`, `shield_list_menu`.**
  - Пункт в MENU_ITEMS для обоих режимов. Клавиша s, в русской раскладке ы.
  - Строка: «вкл · N сетей · список от ДД.ММ» / «выкл» / «✗ не работает».
  - Экран по образцу «Компонентов»:
    - сведения: состояние, число сетей, сколько исключено, дата списка, последняя проверка, отброшено пакетов;
    - переключатели: сканеры, ВК;
    - действия: обновить списки, исключения, добавки, удалить защиту, назад.
  - Сводка при входе показывает замечания защиты (`shield_probs`).
- **Командная строка: `shield_cli`** — `--shield status|on|off|vk on|vk off|update|check|remove`.
  - Коды: 0 работает, 1 не работает, 3 не стоит.
  - Без tty `off` и `remove` работают только с `--yes`.
- **Блокировка: `_shield_lock`.** Таймер и меню не применяют правила одновременно.
- **Файлы и права.** Каталог 0700, файлы 0600: принятые списки, хеш и дата, settings, allow, block, shield.nft, shield.log.

  - Разбор списка: хороший, шире /8 и /16, мусор, мало, много, меньше половины прошлого. Частные сети и адрес сервера выкидываются. Отказ оставляет прошлый список.

  - Ключи меню совпадают с ветками обработчика. Эталоны главного меню g1/46 и g2/80 на двух языках.

## Риск

Высокий: сеть, SSH, чужой ввод, установка пакета.
- **Остаться без SSH.** Порты берутся у sshd на каждом применении. Established-соединения пропускаются раньше drop. Перед загрузкой `nft -c`. Правила только в своей таблице, адреса сервера и частные сети исключены. Остаточный риск: sshd слушает порт, которого нет ни в выводе ss, ни в конфиге. Тогда новые входы с адресов из списка не пройдут, а текущая сессия останется.
- **Испорченный источник.** Строгий разбор и пороги размера; при отказе работает прошлый список.
- **`vk on`.** Сам сервер тоже не ходит в сети ВК: Xray goVLESS pro, обновления, всё остальное. Это сказано на экране.
- **Лимит API.** Хеш запрашивается раз в сутки на сервер, без ключа (60 запросов в час на IP), так что хватает.
- **Откат goInstaller.** (Исправлено вторым заходом, REPORT-fixer-2.txt.) Таймер зовёт свою копию `shield/runner.sh`, поэтому `goinstall --self-update` на версию без защиты защиту не ломает: правила и таймер остаются, goInstaller предупреждает и называет команду снятия `bash /opt/go-installer/shield/runner.sh --shield remove --yes`.

## Как откатить

- На сервере: `goinstall --shield remove --yes`.
- Вручную:
  ```
  nft delete table inet goinstall_shield
  systemctl disable --now goinstall-shield.timer goinstall-shield.path goinstall-shield.service
  rm -f /etc/systemd/system/goinstall-shield.service /etc/systemd/system/goinstall-shield.timer /etc/systemd/system/goinstall-shield.path
  systemctl daemon-reload
  rm -rf /opt/go-installer/shield
  ```
- Goinstall уже без защиты: `bash /opt/go-installer/shield/runner.sh --shield remove --yes` (копия скрипта той версии, что ставила защиту).
- После `--uninstall` версии без защиты: юниты остаются, но служба не запускается (`ConditionPathExists` на runner.sh, каталог снят); таблица живёт до перезагрузки — снять первой командой из ручного списка, юниты — остальными.
- Версия: снимать защиту перед откатом не обязательно (правила ведёт копия), но если она не нужна — сначала `goinstall --shield remove --yes`, потом `goinstall --self-update release-1.1.0`.
- Код: ветка не слита; при необходимости `git revert` коммитов второго захода (список в REPORT-fixer-2.txt), затем `f683c8c 03b9fbe`.

## Что нельзя проверить без сервера

- Примет ли ядро icmpx admin-prohibited в inet forward/output, auto-merge на больших наборах, `nft -c` с `delete table` на чистой системе.
- Точный формат `nft list table` на nft 1.0.2 (22.04) и 1.0.9 (24.04): от него зависит разбор самопроверки и счётчиков.
- Перехват трафика в контейнеры Docker (userland-proxy false) и DNAT goKaskad pro на prerouting -150.
- Поведение таймера и службы при загрузке, сдвиг по времени.
- Реальная установка пакета nftables через apt.
- OpenVZ/LXC: определение контейнера и отказ словами.

## Чего не хватало в ТЗ (решил сам, можно пересмотреть)

- Умолчание в предложении — «Да», как у MTU.
- `--shield check` при выключенных и сканерах, и ВК → код 3 («не стоит»).
- «Исключено» на экране — сумма TVK-AS, своих исключений и выброшенных из списка сетей.
- Сеть есть и в исключениях, и в добавках → побеждает исключение (SSH и доступ важнее).
- Ошибка при применении (не `nft -c`, а сама загрузка) → сервер отмечается «не поддерживается», правила не ставятся; повторить можно из меню.
- Пустой список ВК — допустимое состояние, а не поломка.
- Сменились порты SSH или адреса сервера → таймер пересобирает правила.

## Команды для стенда (Ubuntu 22.04 и 24.04, root)

1. Поставить и включить защиту:
   ```
   goinstall --self-update test-shield
   goinstall            # предложение после языка → 1
   goinstall --shield; echo rc=$?    # ждём 0
   ```
2. Посмотреть правила и юниты:
   ```
   nft list tables
   nft list table inet goinstall_shield | head -60
   systemctl list-timers goinstall-shield.timer
   systemctl is-enabled nftables; systemctl is-active nftables   # как было до установки
   ```
3. Права и журнал:
   ```
   stat -c '%a %n' /opt/go-installer/shield /opt/go-installer/shield/*   # 700 / 600
   tail -20 /opt/go-installer/shield/shield.log
   ```
4. SSH: новый вход из другого окна должен проходить.
5. Восстановление:
   ```
   nft delete table inet goinstall_shield
   goinstall --shield tick                          # в журнале «восстановлено»
   goinstall --shield check; echo rc=$?             # 0
   ```
6. Перезагрузка: `reboot`, затем `nft list tables` и строка «после загрузки» в shield.log.
7. ВК:
   ```
   goinstall --shield vk on
   curl -m 5 https://vk.com; echo rc=$?    # быстрый отказ, rc 7, а не тайм-аут
   goinstall --shield vk off
   ```
8. Обновление и исключения:
   ```
   goinstall --shield update
   ```
   В меню s → исключения: 203.0.113.0/24 принимается, 10.0.0.0/8 отклоняется.
9. После установки goKaskad pro или goAmnezia pro: `nft list tables` (их таблицы на месте), `goinstall --shield check`.
10. Снятие:
    ```
    goinstall --shield remove --yes
    goinstall --uninstall    # подтверждение упоминает защиту
    ```
