# Передача в разработку: интерфейс goInstaller в SSH-терминале

## Коротко

Новый интерфейс `goinstall` (bash, `go-installer.sh`). В него входят:
- сводка при входе по SSH;
- заставка с опросом GitHub;
- главное меню из двух окон;
- мастер установки: режим → проверка портов → ветка → подтверждение → установка → сверка;
- карта портов, ключ доступа, язык;
- экраны ошибок.

Выбранное направление стиля — **«Аркада»**: двойные рамки ╔═╗ с градиентом, тень окон ░, объёмный значок GO. Три других направления («Спокойный», «Ночной», «Фосфор») лежат в спецификации как запасные. Реализовывать их не обязательно.

## Что в архиве

```
README.md                      этот файл — главный документ
brief/claude-design-brief.md   исходный бриф: ограничения терминала, данные, правила текста
prototype/                     живой HTML-прототип (открыть в браузере)
  goInstaller Prototype v2.dc.html
  support.js                   рантайм прототипа, должен лежать рядом
spec/
  tokens.json                  токены цвета: truecolor, xterm-256, ANSI-16, без цвета (все 4 направления)
  ascii-fallback.json          замена каждого символа на ASCII, ширина 1 клетка
  screens/<dir>_<lang>.json    каждый экран × состояние × ширина 80/46, построчно, сегментами
```

**HTML — это эталон, а не код для переноса.** Задача — повторить экраны в bash через `printf` и ANSI-последовательности, клетка в клетку. Ориентироваться на `spec/screens/arcade_ru.json` и `arcade_en.json`: там построена каждая строка каждого экрана. Прототип нужен, чтобы увидеть поведение: клавиши, анимацию, переходы.

## Точность

Высокая. Раскладка по клеткам, тексты и цвета окончательные. Строка в JSON — ровно то, что печатается: пробелы явные, длина не больше `cols`.

## Как читать `spec/screens/*.json`

```json
{ "id": "g2", "label": "Две панели", "state": "problems",
  "screen": "menu", "dir": "arcade", "lang": "ru", "cols": 80, "rows_max": 24,
  "rows": [ [["╔═ ","grad"],["ПРОДУКТЫ","title"], ...], ... ],
  "anim": "…правило анимации, если экран анимирован…" }
```

- **`rows`** — ровно 24 строки (у «окно слишком мало» — 16 строк по 40 колонок). Каждая строка — массив сегментов `[текст, токен]`.
- **Токен с суффиксом `+sel`** означает выделенную строку: сегмент печатается с фоном `sel` (см. ниже).
- **`state`** — сценарий данных: `ok` (всё актуально), `updates` (есть обновления), `problems` (обновления и проблемы). Экспорт сделан в состоянии `problems`, кроме `a2` (всё актуально).
- **Анимированные экраны** выгружены одним кадром: `v1` — середина опроса, `b` — отсчёт. Правило анимации — в поле `anim` и в разделе «Анимация» ниже.

## Разметка «Аркады», 80 × 24

```
строка 1       HUD: " goInstaller 0.9.5  ·  vpn-fin-1" … "диск ▕███▍░░▏58 %  озу ▕██▍░░░▏41 %  нагр 0.4"
строки 2–19    два окна рядом, высота 17 строк внутри + 2 строки рамки
               левое окно: ширина 37 (меню), 40 (меню продукта), 26 (мастер), 28 (порты), 30 (ключ, язык)
               сразу после каждого окна справа — колонка тени '░' (со 2-й строки окна)
строка 20      нижняя тень: пробел + '░' × ширина окна, под каждым окном
строки 21–22   замечания "! …" (только в меню) или пусто
строка 23      инфо: "сведения от 14:05 · обновляются сами раз в 3 мин" / легенда статусов портов
строка 24      подсказка клавиш
```

**Рамка окна `frame2(W, H, title, right)`:**
- **Верх:** `╔═ ` + заголовок + ` ` + `═`×N + ` ` + правая метка + ` ═╗`. Если правая метка не помещается, её нет.
- **Бока:** `║` + содержимое шириной W−2 + `║`.
- **Низ:** `╚` + `═`×(W−2) + `╝`.
- **Цвет:** все символы рамки — токен `grad`, цвет плавно меняется по номеру колонки (см. «Градиент»).

**Выделенная строка внутри окна** залита фоном `sel` на всю внутреннюю ширину окна, но не за его пределами. Курсор — `▸ `.

**Проверка портов (Е)** идёт в одном широком окне шириной 79. Над ним строка шагов: `✓ Режим → ● Проверка → ○ Ветка → ○ Установка → ○ Сверка`.

**46 колонок:**
- одно окно шириной 45 с тенью;
- шаги мастера — строкой над окном: «Шаг 2 из 5 · Проверка → Ветка»;
- список пунктов идёт после содержимого, через разделитель `─`.

## Значок GO

Сетка 4 × 18, каждая строка своим токеном: `logo0` … `logo3`, сверху вниз.

```
▄██████▄  ▄██████▄
██        ██    ██
██  ████  ██    ██
▀██████▀  ▀██████▀
```

**Объём.** Для каждой пустой клетки (r, c), у которой клетка (r−1, c−1) закрашена, печатается `▓` токеном `shade`. В строке под значком (r = 4) вместо `▓` идёт `▀`. Итог: 5 строк × 19 колонок.

**Строки скорости.** На 80 колонках слева от значка, токен `grad`:
```
"      ", "  ════", "══════", " ═════", "      "
```

**Текст справа** от значка, через 3 пробела:
- строка 2: `goInstaller 0.9.5`;
- строка 3: `установщик продуктов серии go`;
- строка 4: `vpn-fin-1 · Ubuntu 24.04.3 LTS`.

**Градиент (`grad`).** Цвет клетки в колонке c равен `lerp(from, to, c / (cols − 1))` по каналам RGB. В режиме 256 цветов каждый результат приводится к ближайшему цвету куба 16–231 или серой шкалы 232–255. В режиме ANSI-16 градиента нет: один код `34;1`.

**Последовательности:**
- truecolor: `\e[38;2;R;G;Bm`, фон — `\e[48;2;R;G;Bm`;
- 256 цветов: `\e[38;5;Nm` / `\e[48;5;Nm`;
- 16 цветов: коды SGR из таблицы выше;
- сброс после каждого сегмента: `\e[0m`.

Выбор режима:
- truecolor, если `COLORTERM` равен `truecolor` или `24bit`;
- 256 цветов, если `TERM` содержит `256color`;
- иначе 16 цветов;
- без цвета при `NO_COLOR`, `TERM=dumb` или выводе не в терминал.

**Фон светлый или тёмный.** Узнать его надёжно нельзя. Предлагаю так:
- по умолчанию тёмная палитра;
- `GOINST_BG=light` включает светлую;
- автоматически: светлая, если `COLORFGBG` кончается на `;15` или `;7`, либо если это Терминал macOS (`TERM_PROGRAM=Apple_Terminal`) и фон не задан.

## Символы и ASCII

- **Какие символы.** Все, что встречаются в JSON, есть в брифе, раздел 2. Эмодзи, Nerd Font и знаков неоднозначной ширины нет.
- **Когда включается ASCII.** Если локаль не UTF-8 (`locale charmap` ≠ `UTF-8`) или задано `GOINST_ASCII=1`, каждый символ заменяется по `spec/ascii-fallback.json`.
- **Замена в одну клетку.** Каждая замена занимает ровно одну клетку: `→` → `>`, `…` → `.`, `╔═╗` → `+=+`, `░` → `.`, `▓` → `#`, спиннер → `| / - \`. Колонки не съезжают.

**Ширина строки в bash.** `printf '%-20s'` считает байты, и кириллица разъезжается. Дополнять пробелами нужно по `${#var}` в UTF-8-локали: bash считает символы. Либо заранее собрать строку сегментов и считать длину без ANSI-последовательностей.

## Управление

Общие правила — бриф, раздел 3. Как это сделано в прототипе:

- **Выбор:** ↑↓ и Enter, цифра срабатывает сразу. Enter без движения выбирает умолчание: курсор стартует на нём (у режима goAmnezia pro это 4, Lite).
- **0** — назад. На главном меню это выход.
- **q** — выход из любого экрана. **Esc** — назад, на главном меню — выход.
- **Служебные клавиши** работают с любого экрана, кроме ввода ключа:
  - `p` — карта портов;
  - `r` — ключ доступа;
  - `l` — язык;
  - `u` — обновить goInstaller, только когда вышла 0.9.6.
- **Русская раскладка.** `з к д г й` означают `p r l u q`. Байты кириллицы приходят в `read`, их надо сопоставить.
- **Ввод ключа.** Символы показываются звёздочками `*`, Backspace стирает, Enter проверяет, Esc — назад.
- **Сводка с отсчётом (Б).** Enter открывает goinstall, любая другая клавиша — консоль, по таймауту 5 секунд — тоже консоль.
- **Заставка (В).** Любая клавиша во время опроса открывает меню, а опрос идёт дальше. В меню внизу крутится «⠋ опрос GitHub: 5 из 8», по окончании меню перерисовывается.

## Переходы

```
вход по SSH → сводка (А) или сводка с отсчётом (Б)
goinstall   → нет ключа?            → К «Нет ключа» → ввод ключа → меню
            → сведения свежие?      → меню
            → иначе                 → заставка (В): опрос 8 запросов
                 ↳ GitHub недоступен → К «GitHub недоступен» (1 меню · 2 повторить · 0 выход)
                 ↳ лимит             → К «Лимит» (то же)
                 ↳ есть новое        → «Что нового» → Enter → меню
                 ↳ нового нет        → сразу меню
меню → 1–6 продукт (Д) → Установить / Обновить или переустановить
        → [режим, если у продукта есть режимы]
        → проверка портов (Е): препятствия → «Выбрать другой режим» / 0
                               нет → Продолжить
        → [ветка, если есть dev] → подтверждение 1 Да / 2 Нет
        → установка (управление штатному установщику) → сверка (З)
     → 7 карта портов (И) · 8 ключ · 9 язык · u обновить goInstaller · 0 выход
```

**Какие режимы есть** — функции `prod_modes` и `prod_mode_choices` в `go-installer.sh`:
- goVLESS pro и goTelegram pro: pro, Lite;
- goAmnezia pro: Ленивый pro, pro, Semi-pro, Lite;
- у остальных режимов нет.

**Ветка dev** есть у goVLESS pro, goTelegram pro, goDNS pro и goAmnezia pro.

**Шаги мастера** строятся по продукту: Режим (если есть режимы) → Проверка → Ветка (если есть dev) → Установка → Сверка.

## Откуда берутся данные

Всё, что показывает экран, у goInstaller уже есть или считается:
- версии и ветки — из опроса GitHub;
- «установлен» — `prod_installed`;
- готовность — `preflight`, та же, что у `--check`;
- порты — `prod_ports` и `port_holders`;
- службы — systemd и docker;
- диск, память, нагрузка — `df`, `/proc/meminfo`, `/proc/loadavg`;
- сертификат — срок из файла Let's Encrypt;
- перезапуски службы — `systemctl show -p NRestarts` или журнал за час.

Трафика, скорости и числа пользователей в интерфейсе нет.

В карточке продукта (правое окно меню) показаны:
- статус в рамке;
- описание;
- таблица «ВЕТКА / СЕРВЕР / GITHUB»;
- «ПОРТЫ» — для установленного; для неустановленного «НУЖНЫ» и «ИТОГ» проверки в режиме по умолчанию;
- «СЛУЖБЫ»;
- «ЧТО НОВОГО»;
- команда продукта.

**Шкалы в HUD.** Ширина 6 клеток на 80 колонках и 4 на 46. Цвет: `ok` меньше 70 %, `warn` меньше 90 %, дальше `err`.

## Анимация

- **Частота.** Не больше 10 кадров в секунду. Перерисовка на месте: курсор в начало (`\e[H`), каждая строка кончается `\e[K`, в конце кадра `\e[J`. Курсор скрыт `\e[?25l`, при выходе его надо вернуть (`trap`).
- **Спиннер.** `⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏`, один кадр на тик.
- **Шкала опроса.** `ответы / 8`, ширина 24 клетки (14 на 46 колонках). Шаг ⅛ клетки: `▏▎▍▌▋▊▉█`, остаток `░` токеном `rule`. Шкала показывает только реальный ход опроса, никаких задержек ради красоты.
- **Отсчёт (Б).** Шкала 24 клетки (20 на 46 колонках) убывает за 5 секунд, справа «N с».
- **«НАЖМИТЕ ENTER».** Мигает раз в 500 мс, только в «Аркаде».
- **Пропуск.** Любая клавиша пропускает анимацию.

## Размер окна

Проверять `tput cols` и `tput lines`:
- 80 колонок и больше — раскладка на 80;
- от 46 до 79 — раскладка на 46;
- меньше 46 × 24 — экран К «Окно слишком мало» (40 × 16), с подсказкой `goinstall --list`.

Перерисовывать по `SIGWINCH`.

## Как пользоваться прототипом

Открыть `prototype/goInstaller Prototype v2.dc.html` в браузере; `support.js` должен лежать рядом.

- **Над терминалом** — переключатели: направление, ширина, цвет, фон, символы, язык, раскладка меню, сценарий, свежесть сведений, сеть и ключ, вход, итог установки.
- **Слева** — быстрый переход к любому экрану.
- **Справа** — клавиши текущего экрана и JSON этого экрана. Кнопка «Скачать все экраны (JSON)» выгружает свежий набор в выбранном направлении.

## Допущения, которые надо сверить с реальностью

- **Порт goTelegram pro 2443.** Он условный: на сервере-примере 443 занят goVLESS pro, поэтому goTelegram pro стоит в режиме Lite.
- **Статус goAmnezia pro — «только Lite».** Так выходит по проверке портов из брифа: режимы с сайтом упираются в TCP 443 и 80.
- **Экран установки.** Во время установки идёт вывод штатного установщика продукта как есть. В прототипе он заменён заглушкой со спиннером.
- **Сообщения о проблемах.** Каждое кончается следующим шагом: `→ certbot renew`, `→ journalctl -u dnsdist`. Команды взяты из здравого смысла — стоит проверить, что их советует сам продукт.
